# Debrief config: fill this in once per team

> Every value below is an **example**. Replace with your own before the first run.

## Where events live

| Setting | Example |
|---|---|
| Events tracker | Notion database "Events" |
| Date property | `Date` |
| Format / Region | `Format`, `Region` |

| Debrief link property | `Debrief Link` |
| Event folder property | `Folder` |
| House outline | `templates/debrief-outline.md` (or a link to your team's template doc) |

## ICP title rule

- **Primary:** CFO, Controller, VP / Director / Head of Finance, Chief Accounting Officer
- **Secondary:** CTO / CIO / CEO / Founder *at a software or tech company*
- **Exclude:** vendor or sponsor staff, non-finance functions, excluded industries

## Naming

- Event ID: `EVT-001`, `EVT-002`, …
- Files: `<EVENT-ID>_<TYPE>_<ShortName>`. Types: `CONTRACT`, `TARGETS`, `LEADS`, `DEBRIEF`
- Due: 3 business days after the event date
